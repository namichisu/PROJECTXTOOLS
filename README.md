# PROJECTX Tools — React

## Overview
PROJECTX Tools is a collection of over 60 free web utilities (PDF, image, text, developer, student, and finance tools) built with React, Vite, and modern UI design. The app provides a fast, responsive, and mobile‑friendly interface that runs entirely in the browser.

## Demo Screenshot
![Demo screenshot](https://github.com/namichisu/PROJECTXTOOLS/raw/master/public/screenshot.png)

## Install
```bash
npm install
```

## Run
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Contributing
Feel free to open issues or submit pull requests. Follow the standard GitHub workflow, run `npm run lint` before committing, and keep the UI consistent with the existing design.
